# AWS Amplify Rekognition Project Setup

## 1. Overview

This document provides a complete setup guide for creating and deploying a full-stack image recognition web application using **AWS Amplify**, **Lambda**, and **Rekognition**. The application allows users to upload an image, process it through a Lambda function, and return image labels generated by Rekognition.

---

## 2. Prerequisites

- AWS Account (with billing enabled)
- Node.js and npm installed
- Amplify CLI installed (`npm install -g @aws-amplify/cli`)
- GitHub account (for repository hosting)
- Web frontend (React or similar)

---

## 3. Amplify Project Initialization

1. Initialize a new Amplify project:

   ```bash
   amplify init
   ```

2. Select the default AWS profile and desired region.
3. Choose the text editor and framework (React recommended).
4. Confirm configuration.

---

## 4. Backend Setup (Lambda + Rekognition)

### 4.1 Add Function

1. Add a new Lambda function to the Amplify backend:

   ```bash
   amplify add function
   ```

2. Choose **Lambda function**.
3. Set the function name to `ImageLabeler`.
4. Select the runtime (Node.js recommended).
5. Choose **“Hello World”** as the starting template.
6. Grant access to AWS Rekognition when prompted.

### 4.2 Modify Function Code

Edit `amplify/backend/function/ImageLabeler/src/index.js`:

```js
const AWS = require('aws-sdk');
const rekognition = new AWS.Rekognition();

exports.handler = async (event) => {
  const { imageBase64 } = JSON.parse(event.body);

  const params = {
    Image: { Bytes: Buffer.from(imageBase64, 'base64') },
    MaxLabels: 10,
    MinConfidence: 70
  };

  try {
    const response = await rekognition.detectLabels(params).promise();
    return {
      statusCode: 200,
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(response.Labels)
    };
  } catch (error) {
    return { statusCode: 500, body: JSON.stringify(error) };
  }
};
```

### 4.3 Push the Function

Deploy the function to AWS:

```bash
amplify push
```

---

## 5. Permissions and Roles

- Amplify automatically creates an **IAM Role** for the Lambda function.
- Ensure the following permission policy is attached to the role:

  ```json
  {
    "Effect": "Allow",
    "Action": ["rekognition:DetectLabels"],
    "Resource": "*"
  }
  ```

- Optionally add **CloudWatch Logs** permissions for monitoring Lambda execution.

---

## 6. API Integration

### 6.1 Add API Gateway

Link the function to an API endpoint:

```bash
amplify add api
```

- Choose **REST API**.
- Use the existing `ImageLabeler` Lambda function.
- Set a path like `/label`.

### 6.2 Deploy API

Push the API changes:

```bash
amplify push
```

---

## 7. Frontend Setup

### 7.1 Configure Amplify in the Frontend

Install Amplify libraries:

```bash
npm install aws-amplify
```

Add configuration to the React project (`src/aws-exports.js` is auto-generated):

```js
import Amplify, { API } from 'aws-amplify';
import awsExports from './aws-exports';
Amplify.configure(awsExports);
```

### 7.2 Image Upload & Label Request

Create a function to call the API:

```js
async function getImageLabels(base64Image) {
  const data = { body: { imageBase64: base64Image } };
  return await API.post('apiName', '/label', data);
}
```

---

## 8. Hosting the Application

### 8.1 Connect Repository

1. Push the project to GitHub.
2. Go to the **AWS Amplify Console**.
3. Choose **Host Web App**.
4. Connect to the GitHub repository.
5. Select the branch to deploy.
6. Configure the build settings (Amplify auto-detects React).

    6.5. App page -> Hosting -> Build settings -> Edit amplify.yml as such:

    ```yml
    version: 1
    frontend:
      phases:
        preBuild:
          commands:
            - cd frontend
            - npm i
        build:
          commands:
            - npm run build
      artifacts:
        baseDirectory: frontend/build
        files:
          - '**/*'
      cache:
        paths:
          - frontend/node_modules/**/*
    ```

7. Deploy.

### 8.2 Continuous Deployment

- Each Git commit to the connected branch triggers an automatic redeploy.
- Monitor deployment progress in the Amplify Console.

---

## 9. Monitoring & Logging

- View Lambda logs in **CloudWatch**.
- Monitor function performance, API calls, and errors.

---

## 10. Optional Enhancements

- Enable authentication (`amplify add auth`) for user-based upload tracking.
- Use **S3** for image storage instead of base64 strings.
- Add **CORS** rules for frontend API access.

---

## 11. Summary

This setup provides a fully functional image recognition web application using:

- **Amplify** for project management and hosting
- **Lambda (ImageLabeler)** for backend processing
- **Rekognition** for AI-based image analysis
- **CloudWatch** for monitoring and logging
